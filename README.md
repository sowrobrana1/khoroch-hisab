# খরচের হিসাব

ব্যক্তিগত দৈনন্দিন খরচের হিসাব — অফলাইনে চলে, লগইন নেই, Play Store-এ যাবে না।

## যা করে
- প্রতিদিনের খরচ লেখা: তারিখ (আজকের তারিখ ডিফল্ট, বদলানো যায়) | কোথায় খরচ | টাকা
- তালিকা নিচের দিকে সিরিয়াল ধরে বাড়ে — পুরোনো উপরে, নতুন নিচে
- প্রতিটা লাইনের পাশে চলমান মোট (ওই লাইন + ওপরের সবগুলো); শেষ লাইনের মোট = সব মিলিয়ে মোট
- উপরে সব মিলিয়ে মোট আলাদা করে দেখা যায়
- কোনো লাইনে চেপে ধরলে মুছে ফেলা যায় (ভুল লিখলে), মোট নিজে নিজে ঠিক হয়ে যায়
- বাংলা লেখা + বাংলা সংখ্যা (০-৯); হিসাব শুধু ফোনে থাকে (SQLite)

## বিল্ড
- Native Android (Kotlin, Gradle), package `com.sowrobrana.khorochhisab`
- GitHub Actions CI (`.github/workflows/build.yml`): unit test + `assembleDebug` → `khoroch-debug-apk` artifact
- Debug APK সই করা হয় `debug.keystore` দিয়ে (alias `khoroch-debug`) — একই key দিয়ে পরের আপডেটগুলোও সই হবে, তাই আপডেট পুরোনো ভার্সনের ওপরে বসবে
