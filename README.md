# খরচের হিসাব

ব্যক্তিগত দৈনন্দিন খরচের হিসাব — অফলাইনে চলে, লগইন নেই, Play Store-এ যাবে না।

## যা করে
- প্রতিদিনের খরচ লেখা: তারিখ (আজকের তারিখ ডিফল্ট, বদলানো যায়) | কোথায় খরচ | টাকা
- তালিকা নিচের দিকে সিরিয়াল ধরে বাড়ে — পুরোনো উপরে, নতুন নিচে
- প্রতিটা লাইনের পাশে চলমান মোট (ওই লাইন + ওপরের সবগুলো); শেষ লাইনের মোট = সব মিলিয়ে মোট
- উপরে সব মিলিয়ে মোট আলাদা করে দেখা যায়
- কোনো লাইনে চেপে ধরলে মুছে ফেলা যায় (ভুল লিখলে), মোট নিজে নিজে ঠিক হয়ে যায়
- বাংলা লেখা + বাংলা সংখ্যা (০-৯); হিসাব শুধু ফোনে থাকে (SQLite)

## v2 (2026-11-07) — হিসাবের খাতা + শেয়ার
- উপরে ৩ বোতাম: "নতুন হিসাব শুরু" / "পুরোনো হিসাব" / "শেয়ার"।
- "নতুন হিসাব শুরু": নিশ্চিতকরণের পর চলমান হিসাবটা তারিখের নামে আলাদা ফাইলে জমা হয় (যেমন "৬ নভেম্বর, ২০২৬ – ৩ ডিসেম্বর, ২০২৬"), নতুন হিসাব খালি থেকে শুরু হয়। সময়সীমা নিজের হাতে (২৭ দিন / ৩৪ দিন যেকোনো) — মাসের হিসাব অটো হয় না।
- "পুরোনো হিসাব": বন্ধ হওয়া খাতাগুলোর তালিকা (তারিখ, কয়টি খরচ, মোট) — যেকোনো একটায় চাপ দিলে ওই খাতার সব লাইন (চলমান মোটসহ) দেখা যায়, শুধু দেখা যায় — বদলানো যায় না।
- শেয়ার (চলমান হিসাব + যেকোনো পুরোনো ফাইল): ছবি হিসেবে (সাজানো ছবি — সিরিয়াল ঠিক) বা লেখা হিসেবে (লাইন ধরে লাইন নোট) — Android শেয়ার মেনু দিয়ে WhatsApp/Messenger-এ পাঠানো যায়।
- ডাটা নিরাপত্তা: v1 থেকে v2-তে আপডেট করলে পুরোনো সব খরচ অটো একটা "চলমান হিসাব" খাতায় চলে আসে — কিছু মোছা হয় না (DB migration v1→v2: ledgers টেবিল + ledger_id, কোনো DROP নেই)। একই package + একই debug.keystore দিয়ে সই হয়, তাই v2 পুরোনো v1-এর ওপরে বসে।

## বিল্ড
- Native Android (Kotlin, Gradle), package `com.sowrobrana.khorochhisab`
- GitHub Actions CI (`.github/workflows/build.yml`): unit test + `assembleDebug` → `khoroch-debug-apk` artifact
- Debug APK সই করা হয় `debug.keystore` দিয়ে (alias `khoroch-debug`) — একই key দিয়ে পরের আপডেটগুলোও সই হবে, তাই আপডেট পুরোনো ভার্সনের ওপরে বসবে
